# Каталог сценариев — Telegram Mini App

Публикуется как статический сайт (GitHub Pages). Точка входа — `index.html`.

| Файл | За что отвечает |
|---|---|
| `index.html` | разметка четырёх экранов и нижнего меню |
| `app.css` | вид: тема Telegram (светлая/тёмная), карточки, меню |
| `app.js` | поиск, фильтры, переходы, копирование промпта, заявка |
| `data.js` | контент: направления и 50 сценариев |

## Что менять

- Тексты и сценарии — `data.js`.
- Контакт для заявок — константа `CONTACT` в `app.js`.
- Цвета бренда — переменные `--brand` и `--accent` в `app.css`.

## Проверка

Открыть `index.html` в браузере на ширине 390 px. Внутри Telegram приложение
дополнительно включает системную кнопку «Назад», главную кнопку и вибрацию.
